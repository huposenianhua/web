关于 Palmmicro

Palmmicro 是一个股票数据分析和交易管理平台，提供中美港三地股票实时行情查询、QDII基金净值估算、配对交易分析等功能。

功能特性

  • 实时行情获取 - 新浪财经、Yahoo Finance
  • 基金净值估算 - QDII基金实时净值
  • 配对交易分析 - A/B股、A/H股、ADR比价
  • 投资组合管理 - 多币种持仓管理
  • 技术分析 - SMA、EMA、布林带

技术架构

本项目是 Palmmicro PHP 原版的 Python 复刻版本，使用 Flask 框架构建 Web 应用。
