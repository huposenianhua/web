# 🔍 基础计算与因子调整详解

## 🎯 核心公式

```
① 基础计算：raw_value = XOP_price × USDCNY_rate
② 因子调整：estimated_nav = raw_value / calibration_factor
```

---

## 一、基础计算：`raw_value = XOP_price × USDCNY_rate`

### 📊 变量解析

| 变量 | 含义 | 单位 | 来源 |
|------|------|------|------|
| `XOP_price` | XOP ETF的实时价格 | 美元($) | 新浪美股/Yahoo Finance |
| `USDCNY_rate` | 实时美元兑人民币汇率 | 无 | 新浪外汇/中国货币网 |
| `raw_value` | XOP的人民币价值 | 人民币(¥) | 计算得出 |

### 🧮 数学含义

**本质**：将XOP的美元价格转换为**人民币计价**

**含义解读**：
> **当前时刻，1份XOP ETF的人民币价值是多少。**

### 📈 计算示例

**实时数据**（假设）：
- XOP实时价：$82.15
- USDCNY汇率：7.2150

**计算过程**：
```
raw_value = 82.15 × 7.2150
          ≈ 592.71元
```

**含义**：当前1份XOP ETF的人民币价值约为 **592.71元**。

---

## 二、因子调整：`estimated_nav = raw_value / calibration_factor`

### 📊 变量解析

| 变量 | 含义 | 单位 | 来源 |
|------|------|------|------|
| `raw_value` | XOP的人民币价值 | 人民币(¥) | 基础计算得出 |
| `calibration_factor` | 校准因子 | 无 | 历史数据计算 |
| `estimated_nav` | 基金的估算净值 | 人民币(¥) | 计算得出 |

### 🧮 数学含义

**本质**：根据历史比例关系，将XOP的人民币价值**转换为对应的基金净值**

**含义解读**：
> **如果XOP当前值raw_value元人民币，那么对应的基金净值应该是多少。**

### 📈 计算示例

**数据**：
- raw_value：592.71元（来自基础计算）
- calibration_factor：672.35（历史计算得出）

**计算过程**：
```
estimated_nav = 592.71 / 672.35
              ≈ 0.8815元
```

**含义**：根据XOP当前价格估算，基金的实时净值约为 **0.8815元**。

## 四、为什么需要这两步？

### 1. **第一步：单位统一**
```
问题：XOP以美元计价，基金以人民币计价
解决：通过汇率转换为统一的人民币单位
```

### 2. **第二步：比例转换**
```
问题：XOP和基金是不同的金融产品，价值不同
解决：通过校准因子建立比例关系
```

### 3. **本质逻辑**
```
校准因子告诉我们："XOP的价值是基金净值的fFactor倍"
所以：基金净值 = XOP价值 / fFactor
```


**结论**：基金净值估算跟随XOP价格同步变化。

## 六、代码实现示例

### Python实现

```python
def calculate_estimated_nav(xop_price: float, usdcny_rate: float, calibration_factor: float) -> float:
    """
    计算基金的估算净值
    
    Args:
        xop_price: XOP实时价格（美元）
        usdcny_rate: 实时汇率
        calibration_factor: 校准因子
    
    Returns:
        float: 估算净值（人民币）
    """
    # Step 1: 基础计算 - 将XOP价格转换为人民币
    raw_value = xop_price * usdcny_rate
    
    # Step 2: 因子调整 - 转换为基金净值
    estimated_nav = raw_value / calibration_factor
    
    # 精度处理：保留4位小数
    return round(estimated_nav, 4)

# 使用示例
xop_price = 82.15
usdcny_rate = 7.2150
calibration_factor = 672.35

estimated_nav = calculate_estimated_nav(xop_price, usdcny_rate, calibration_factor)
print(f"估算净值: {estimated_nav}元")  # 输出: 0.8815元
```

## ✅ 总结

**两步计算的核心逻辑**：

| 步骤 | 公式 | 作用 | 示例 |
|------|------|------|------|
| 基础计算 | `raw_value = XOP_price × USDCNY_rate` | 将美元转换为人民币 | $82.15 → 592.71元 |
| 因子调整 | `estimated_nav = raw_value / calibration_factor` | 将XOP价值转换为基金净值 | 592.71元 → 0.8815元 |

**本质**：
> 通过"汇率转换 + 比例转换"两个步骤，将海外标的价格转换为国内基金的实时估算净值。

这是QDII基金实时估值的**核心算法**，没有这两步就无法实现跨市场的价格对比！
