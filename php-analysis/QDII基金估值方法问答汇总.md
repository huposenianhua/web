# QDII基金估值方法问答汇总

## 一、美股QDII配对基金的实时溢价率预估方法是否一样？

**答案：并不完全一样，主要取决于基金类型和标的资产特性。**

### 核心差异点

| 基金类型 | 估算公式 | 特点 |
|---------|---------|-----|
| **被动指数型** | `估算净值 = T-2日净值 × (1±标的指数涨跌幅) × T日汇率/T-1日汇率` | 直接跟踪单一指数，计算逻辑简单 |
| **商品类** | `估算净值 = T-2日净值 × (1+ΔPWTI×权重+ΔPBRENT×权重) × 汇率调整` | 需按权重组合多个标的 |
| **主动管理型** | 计算前十大持仓加权涨跌幅，调整总股票仓位影响 | 持仓分散且不透明，估算难度大 |

### 通用估算框架

```
真实溢价率 = (当前场内价格 ÷ 预估净值 - 1) × 100%
```

## 四、所有基金和基金对的估值方法穷举

### 股票型基金

| 子类型 | 估值方法 | 核心逻辑 |
|-------|---------|---------|
| 被动指数型 | 指数跟踪法 | 净值 = 昨日净值 × (1 + 标的指数涨跌幅) |
| 主动管理型 | 持仓估算法 | 净值 = Σ(持仓股票价格 × 数量) / 总份额 |
| 行业主题型 | 行业指数法 | 净值 = 昨日净值 × (1 + 行业指数涨跌幅) |

### 债券型基金

| 子类型 | 估值方法 | 核心逻辑 |
|-------|---------|---------|
| 利率债型 | 贴现现金流法 | 债券价值 = Σ(未来现金流 / (1+收益率)^n) |
| 信用债型 | 信用利差法 | 债券价值 = 无风险价值 + 信用风险溢价 |
| 可转债型 | 期权定价模型 | 价值 = 纯债价值 + 期权价值 |

### QDII基金

| 子类型 | 估值方法 | 核心公式 |
|-------|---------|---------|
| 美股指数型 | 指数跟踪+汇率调整 | 净值 = 昨日净值 × (1 + 美股指数涨跌幅) × 汇率调整 |
| 原油期货型 | 期货价格+汇率调整 | 净值 = 昨日净值 × (1 + WTI/Brent涨跌幅) × 汇率调整 |
| 商品型 | 商品价格+汇率调整 | 净值 = 昨日净值 × (1 + 商品价格涨跌幅) × 汇率调整 |

## 六、以501018为例：网页展示与对冲套利估值方法差异

### 核心差异

| 维度 | 网页展示估值 | 对冲套利估值 |
|-----|------------|------------|
| **方法** | 单一标的参考法 | 持仓明细加权法 |
| **参考标的** | USO（美国原油ETF） | 基金实际持仓的所有标的 |
| **准确性** | 近似估算，存在误差 | 精确计算，误差小 |
| **复杂度** | 简单快速 | 复杂精细 |
| **适用场景** | 日常查看、快速参考 | 套利交易、精确计算 |

### 网页展示估值（单一标的）

```
估算净值 ≈ 昨日净值 × (1 + USO涨跌幅) × 汇率调整
```

**局限性**：
- USO只是501018持仓的标的之一
- 还持有欧洲市场的原油ETF，收盘时间不同
- 市场假期差异导致估算误差

### 对冲套利估值（持仓明细）

```
估算净值 = 持仓基准日净值 × (1 + Σ(持仓权重 × 标的涨跌幅)) × 汇率调整 × 仓位系数
```

## 七、对冲套利中的精确持仓明细计算方法

### 核心计算公式

```
(x - x0) / x0 = Σ{ r × (y - y0) / y0 }

基金净值变化率 = 持仓权重1 × 标的1涨跌幅 + 持仓权重2 × 标的2涨跌幅 + ...
```

### 计算步骤

1. **数据准备**：持仓基准日信息、持仓明细、汇率参考
2. **获取基准日价格**：每个持仓标的在基准日的价格
3. **遍历计算每个标的贡献**：按权重累加
4. **汇率调整**：区分A股/港股/美股分别调整
5. **归一化处理**：按总权重归一化
6. **应用仓位系数**：LOF基金通常使用95%仓位
7. **计算最终净值**

### 实际计算示例

假设501018持仓：

| 标的 | 权重 | 基准日价格 | 当前价格 | 涨跌幅 | 贡献 |
|-----|-----|----------|---------|-------|-----|
| USO | 60% | 50.00 | 52.50 | +5% | 3.0% |
| BNO | 30% | 35.00 | 36.05 | +3% | 0.9% |
| DBO | 10% | 28.00 | 27.44 | -2% | -0.2% |

```
加权平均涨跌幅 = 60%×5% + 30%×3% + 10%×(-2%) = 3.7%
估算净值 = 1.2500 × (1 + 3.7% × 95%) = 1.2939
```

### 汇率调整机制

```php
function RefAdjustForex($ref, $fAdjustHKD, $fAdjustUSD)
{
    if ($ref->IsSymbolA())     $fAdjust = 1.0;        // A股：无需调整
    else if ($ref->IsSymbolH()) $fAdjust = $fAdjustHKD;  // 港股：港币调整
    else                        $fAdjust = $fAdjustUSD;  // 美股：美元调整
    return $fAdjust;
}
```

### 实时估算 vs 官方估算

| 类型 | 数据源 | 用途 |
|-----|-------|-----|
| 官方估算 | 历史收盘价 | 计算溢价率 |
| 实时估算 | 实时交易价 | 盘中套利决策 |

## 附录：项目代码中的核心类职责

### FundReference
- 基础基金参考类
- 管理官方净值、公允价值、实时净值
- 处理仓位调整

### FundPairReference
- 基金配对估值核心类
- 实现从配对标的估算净值
- 处理校准因子更新

### HoldingsReference
- 持仓明细估值类
- 实现多标的加权计算
- 支持实时和历史估值

### _QdiiReference
- QDII基金抽象基类
- 实现核心估值计算
- 管理汇率参考
